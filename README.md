# Haotian Alex Xue — Portfolio

Architecture, urban design, research, exhibition, and graphic work.

## Hosting

GitHub Pages publishes the `docs/` directory on the `main` branch. Enable it in repository Settings → Pages → Deploy from a branch → main → /docs → Save.

Expected URL after Pages is enabled and the deployment succeeds: https://hx2436-ax.github.io/portfolio/

## Editing

Edit the HTML pages in `docs/`, CSS in `docs/style.css`, and JavaScript in `docs/app.js`. Original rendered project images and the résumé are in `docs/assets/`. Project metadata is in `docs/projects.json`. All internal URLs use the `/portfolio/` base path.

The website contains a home page, About, a filterable project index, and ten independent project pages. Images and text were adapted from the supplied September 2026 portfolio and October 2026 résumé. Collaborative project credits are retained.
